## Interactivity
The notebooks included in this book can be launched {{via}}
[Binder](https://jupyter.org/binder) or
[Google Colab](https://colab.research.google.com) so that users can run them
interactively.  Please note that the notebooks often contain cells that are not
present in the book's rendering.  These cells can contain

* commented out lines that can be used to setup a notebook's execution
  environment in Google colab,
* commented out lines that specify other emulator, calibrator, or sampler
  methods that could be used in the notebook, or
* code that checks correct execution of the notebook.

The latter can be ignored since they are for development and maintenance
purposes only.
